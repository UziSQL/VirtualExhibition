# Ұлы дала — виртуальный музей Казахстана

Работающая учебная выставка ко Дню Республики: центральный атриум с мотивом шанырака, шесть соединённых залов, свободная прогулка и экскурсия. Интерфейс и материалы на русском, отдельные подписи на казахском.

## Запуск

Нужен Node.js 22.12+ (проект проверен с Node.js 24).

```sh
npm ci
npm run dev
```

Откройте адрес, выведенный Vite, обычно **http://localhost:5173**. В Windows PowerShell с запретом `.ps1` используйте `npm.cmd ci` и `npm.cmd run dev`. Для просмотра с телефона используйте сетевой адрес Vite, находясь в одной локальной сети с компьютером.

```sh
npm run typecheck   # TypeScript
npm test            # логика паспорта, вопросов, экскурсии и столкновений
npm run build       # готовый сайт в dist/
npm run preview     # локальный просмотр production-сборки
npx playwright install chromium
npm run test:e2e    # браузерные сценарии; сервер запускается автоматически
```

## Что есть в музее

- **История моей страны**: Декларация 1990 года, независимость 1991 года, лента событий и различие двух праздников.
- **Государственные символы**: флаг в пропорциях 1:2, герб, рассказ о гимне со ссылкой на официальный материал.
- **Культурное наследие**: домбра, юрта, ремесло. Две интерактивные объёмные иллюстрации с вращением мышью, пальцем или клавиатурным ползунком.
- **Лица Казахстана**: Абай, Шоқан Уәлиханов и Каныш Сатпаев; настоящие исторические портреты.
- **Моя малая родина**: место для реальных местных материалов; до заполнения не даёт отметку.
- **Казахстан будущего**: образование, наука, экология, сохранение памяти и личное пожелание.

В пяти заполненных залах **14 экспонатов и 5 вопросов**. Экскурсия последовательно показывает все заполненные экспонаты, выделяя 25 секунд на каждую остановку; ориентир с чтением и переходами — 5–7 минут. Доступны пауза, предыдущая/следующая остановка и завершение. Незавершённый региональный зал не выдаётся за готовую экспозицию.

Паспорт отмечает зал только после открытия содержательного экспоната (в том числе при прибытии к нему в экскурсии). Повторное открытие не дублирует отметку. Неверный ответ можно исправить. Прогресс, правильные ответы и пожелание сохраняются в `localStorage` под ключом `uly-dala-passport-v1`. Сброс требует отдельного подтверждения и удаляет также пожелание. При недоступном хранилище сайт сообщает об этом и продолжает работать в памяти.

## Управление

Компьютер: WASD / стрелки — движение; клик по сцене — включение обзора мышью; Esc — освобождение курсора и меню. Подойдите к экспонату ближе 4,5 м, наведите прицел и нажмите E или кликните. Активный прицел подсвечивается золотым.

Телефон: левый джойстик — движение, отдельная правая область «Обзор» — поворот камеры; кнопка «Открыть» или нажатие на близкий экспонат. Кнопки залов и схема музея доступны на всех устройствах.

Стены, границы здания и постаменты участвуют в столкновениях. Автоматические маршруты ищутся по свободной сетке с проверкой той же геометрии. Во время экскурсии ручное движение отключено. Нативные диалоговые окна блокируют фон, удерживают клавиатурный фокус и закрываются по Esc; после закрытия фокус возвращается к вызвавшему элементу, если он ещё существует.

## Заполнение данных перед челленджем

Откройте **`src/data/config.ts`**. В одном месте задаются:

```ts
authors: ['Реальное имя автора'],
organization: 'Реальное название образовательной организации',
region: 'Реальный регион или населённый пункт',
regionalExhibits: [
  {
    id: 'local-landmark',
    title: 'Название местного памятника',
    caption: 'Краткая проверенная подпись',
    paragraphs: ['Рассказ об объекте.', 'Дополнительная история.'],
    image: 'region/landmark.jpg',
    imageCredit: 'Автор фотографии и разрешение / лицензия',
    sourceUrl: '', // вставьте действительную ссылку на проверенный источник
    sourceLabel: 'Название источника',
  },
],
```

Образец выше — схема заполнения, не сведения об участниках. В самом приложении отсутствующие данные явно отмечены. Разместите 2–3 региональных экспоната; фотографию из примера сохраните как `public/images/region/landmark.jpg`. Не публикуйте пример без замены текста и URL. Добавьте вопрос в запись `region` массива `halls` в `src/data/museum.ts`, когда зал будет наполнен.

## Как менять коллекцию

`src/data/museum.ts` содержит типы `Hall`, `Exhibit`, `Question`, `Source` и сами данные. Экспонат с уникальным `id` получает `hall`, `title`, `caption`, массив `paragraphs` и список идентификаторов `sources`. Необязательные поля: `image`, `imageCredit`, `model` (`dombra` или `yurt`), `motif` для оформленной текстовой карточки. Вопрос содержит варианты, индекс правильного ответа с нуля и объяснение.

3D-залы рассчитаны на **2–3 настенных экспоната каждый**. Для большего числа карточек расширьте компоновку `Architecture` в `src/components/MuseumScene.tsx`. Обычный каталог автоматически показывает весь массив. После изменения `id` старые отметки соответствующего экспоната перестанут учитываться — используйте постоянные идентификаторы.

Изображения храните в `public/images/`, используйте относительный путь к этой папке. JPEG/WebP до 1200–1600 px по длинной стороне обычно достаточны. Для государственных символов сохраняйте оригинал, пропорции и все элементы; не заменяйте их генеративной картинкой. Ошибка отдельной картинки оставляет текстовую карточку доступной.

Процедурные модели находятся в `src/components/Models.tsx`; обе помечены как стилизованные иллюстрации. Для новой модели расширьте тип `model` и компонент `ModelShowcase`. Для внешних GLB создайте `public/models/`, загрузите через `useGLTF` из drei внутри локальной границы ошибок и `Suspense`, задайте реальные размеры, добавьте столкновения при размещении в проходе и укажите лицензию. Не включайте чужие модели без разрешения.

## Источники и ресурсы

Посетителю доступна панель **«Источники и материалы»**. Факты сверены с Gov.kz, Ақордой, ЮНЕСКО, порталом истории Казахстана и музеем Satbayev University. Все изображения локальные; подробные исходные метаданные Commons сохранены в `public/images/credits.json`.

- Флаг — Шакен Ниязбеков, Commons / PD-KZ-exempt, 1:2.
- Герб — Жандарбек Малибеков и Шот-Аман Уалиханов; SVG Bingread / Glide08, Commons / PD-KZ-exempt, надпись Qazaqstan.
- Абай и Шоқан — Commons, Public domain / PD-old, авторы не указаны.
- Сатпаев — «Казахстанская правда», 19 мая 1949 года, Commons / PD-Kazakhstan, неизвестный автор.
- Локальные шрифты Golos Text и Noto Serif — SIL Open Font License (копии в `public/licenses/`).

`scripts/fetch-assets.py` воспроизводит загрузку исходных изображений через Commons API; это вспомогательный скрипт Python 3, при обычном запуске сайта не нужен. Условия лицензии и автора всегда проверяйте перед добавлением новых файлов. Аудиозапись гимна не включена; официальный источник указан. Региональные фотографии, истории и сведения об участниках должен предоставить организатор выставки.

## Доступность и производительность

Сцена и просмотр моделей загружаются отдельными модулями. Изображения не зависят от внешнего CDN; шрифты тоже локальные. При неподвижном стартовом экране, паузе экскурсии и открытых карточках используется рендеринг по требованию. Pixel ratio ограничен до 1,5, в низком качестве — 1. Тени выборочные; в низком качестве отключены. В «Авто» узкий экран получает низкое качество.

`prefers-reduced-motion` отключает CSS-анимации и делает переходы мгновенными. При недоступности WebGL2, ошибке сцены или потере контекста предлагаются каталог и повтор загрузки. Каталог можно открыть и при работающем 3D. Фиксированные показатели FPS не заявляются: их нужно измерять на целевых устройствах.

## Публикация

1. Выполните `npm ci`, `npm run typecheck`, `npm test`, `npm run build`.
2. Опубликуйте содержимое `dist/` на статическом хостинге по HTTPS. Сервер приложения и база данных не нужны. `base: './'` позволяет размещать сайт в подпапке, в том числе `/VirtualExhibition/`.
3. Для GitHub Pages в **Settings → Pages → Source** выберите **GitHub Actions**, создайте workflow сборки Node 24 (`npm ci`, `npm run build`), загрузки `dist` через `actions/upload-pages-artifact` и публикации `actions/deploy-pages`. Дайте job права `pages: write`, `id-token: write` и environment `github-pages`.
4. Для Netlify / Vercel: build command `npm run build`, output directory `dist`.
5. После публикации проверьте адрес на компьютере и реальном телефоне, все фотографии, казахские буквы, источники и сведения об участниках.

Проект подготовлен к статическому размещению. Создание внешнего deployment не выполняется автоматически при локальном запуске.
